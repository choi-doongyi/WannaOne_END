# agitator-features · F

| 컬럼 | 정의·단위 |
|---|---|
| SCENARIO_ID | 독립 시나리오 ID; 모든 표의 연결 키 |
| MEAS_DT | 관측 시각(UTC ISO 8601) |
| EQP_CD | 설비 ID; EQP_TAG와 동일한 값 |

| FS_HZ | 표본 주파수(Hz) |
| LOAD | 정격 대비 부하 비율 |
| VISCOSITY | 점도 지표 |
| VIB-AGT_RMS | 진동 진폭 제곱평균제곱근(원 지표 단위) |
| VIB-AGT_STD | 진동 진폭 모집단 표준편차(원 지표 단위) |
| VIB-AGT_KUR | 진동 진폭 초과첨도(무차원) |
| VIB-AGT_CRF | 진동 진폭 첨두율: 절댓값 최대/RMS(무차원) |
