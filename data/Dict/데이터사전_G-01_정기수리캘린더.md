# 데이터사전 — `G-01_정기수리캘린더.csv`

본 데이터는 KAMP 공개 제조AI데이터셋을 원본으로 제철 공정 맥락에 맞게 재구성한 교육용 재현 데이터임. 특정 기업의 실제 조업 데이터가 아님.

---

## 1. 개요

| 항목 | 값 |
|---|---|
| 파일 | `data/G-01_정기수리캘린더.csv` |
| 공정 · 설비 | 소결(SP1·SP2), 냉연(CR1) |
| 계측 | 계측 데이터가 아니라 계획 대장이다 |
| 크기 | 4행 × 5열 |
| 인코딩 | `utf-8-sig` / 줄끝 LF / 구분자 `,` |
| 한 행 | 정기수리 1회 |

---

## 2. 컬럼

| 컬럼 | 한글명 | 타입 | 단위 | 값 범위 | 결측 | 산출 |
|---|---|---|---|---|---|---|
| `PLAN_ID` | 계획번호 | 문자열 | — | `PLAN-2024-01` / `PLAN-2024-02` / `PLAN-2024-03` / `PLAN-2024-04` | 0 |  |
| `PLANT_CD` | 공장코드 | 문자열 | — | `CR1` / `SP1` / `SP2` | 0 | 설비마스터와 잇는다 |
| `STRT_DT` | 시작일 | 문자열 | — | 2024-03-15 ~ 2024-11-05 | 0 |  |
| `END_DT` | 종료일 | 문자열 | — | 2024-03-22 ~ 2024-11-10 | 0 | **당일 포함** |
| `SCOPE` | 작업범위 | 문자열 | — | `냉연 라인 전 설비 정기수리` / `배풍기 정지 및 소결기 정기점검` / `연속소둔로 노내 정비` | 0 |  |

- 컬럼 순서는 `PLAN_ID` `PLANT_CD` `STRT_DT` `END_DT` `SCOPE`

---

## 3. 값을 읽을 때

- **정기수리 기간에는 계측 데이터가 없다.** 해당 공장의 계측 파일에서 이 구간이 통째로 비어 있다. 결측이 아니라 설비 정지다
- **`END_DT` 는 그날까지 포함한다.** 구간 길이를 셀 때 하루를 더해야 한다
