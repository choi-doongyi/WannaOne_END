# 데이터사전 — `G-02_조업이벤트.csv`

본 데이터는 KAMP 공개 제조AI데이터셋을 원본으로 제철 공정 맥락에 맞게 재구성한 교육용 재현 데이터임. 특정 기업의 실제 조업 데이터가 아님.

---

## 1. 개요

| 항목 | 값 |
|---|---|
| 파일 | `data/G-02_조업이벤트.csv` |
| 공정 · 설비 | P제철 전 공장 |
| 계측 | 계측 데이터가 아니라 조업 조건 변경 기록이다 |
| 크기 | 263행 × 6열 |
| 인코딩 | `utf-8-sig` / 줄끝 LF / 구분자 `,` |
| 한 행 | 조업 조건 변경 1건 |

---

## 2. 컬럼

| 컬럼 | 한글명 | 타입 | 단위 | 값 범위 | 결측 | 산출 |
|---|---|---|---|---|---|---|
| `EVT_ID` | 이벤트번호 | 문자열 | — | 263종 (`EVT-2024-0001` ~ `EVT-2024-0263`) | 0 |  |
| `EVT_DT` | 발생시각 | 문자열 | — | 2024-01-02 03:36 ~ 2024-12-31 20:15 | 0 |  |
| `EVT_TYPE` | 이벤트유형 | 문자열 | — | `강종변경` / `원료배합변경` / `조업률변경` | 0 | `강종변경` / `원료배합변경` / `조업률변경` |
| `PLANT_CD` | 공장코드 | 문자열 | — | `BF1` / `BF2` / `CR1` / `SP1` / `SP2` | 0 | 설비마스터와 잇는다 |
| `BEF_VAL` | 변경 전 값 | 문자열 | — | 40종 (`100%` ~ `SPHC`) | 0 | 유형에 따라 의미가 다르다 |
| `AFT_VAL` | 변경 후 값 | 문자열 | — | 42종 (`100%` ~ `SPHC`) | 0 | 유형에 따라 의미가 다르다 |

- 컬럼 순서는 `EVT_ID` `EVT_DT` `EVT_TYPE` `PLANT_CD` `BEF_VAL` `AFT_VAL`

---

## 3. 값을 읽을 때

- **`BEF_VAL` `AFT_VAL` 의 의미가 행마다 다르다.** 강종변경이면 강종명, 조업률변경이면 비율이다. `EVT_TYPE` 을 보지 않고 두 컬럼만 쓰면 안 된다
- **계측 데이터의 분포 변화와 대조해 볼 것.** 조건이 바뀌면 계측값의 분포도 바뀐다. 시간에 따라 분포가 달라지는 상황을 다루는 소재다
